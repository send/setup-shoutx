# v0.2.0 release notes

GitHub Actions workflows can select a provider-specific shoutx binary with the
optional `provider` input. The default is `github-actions`. Existing workflows
installing supported CLI versions through v1.0.0 continue to use their original
archive names. The CLI and installer have independent version numbers.

Azure Pipelines workflows can import the new steps template, which defaults
to `azure-pipelines`. It shares the GitHub Action's release selection,
checksum and archive verification, and native version check. A successful
installation adds the verified directory to PATH in subsequent steps.

Use the [README](../README.md) for inputs and examples and the [release
listing](https://github.com/send/setup-shoutx/releases) for publication status.
